## Read, download and cite / 阅读、下载与引用

- [Public file catalogue](CATALOG.md): PDF, ZIP or HTML links with file sizes and source checksums.
- [Machine-readable catalogue](catalog.json): nine version-specific records, author identifiers, licenses and file URLs.
- [BibTeX references](references.bib): one entry for each version-specific DOI.
- [Change history](CHANGELOG.md).

Zenodo hosts the versioned papers and the files listed in each record. This repository provides navigation and metadata; downloadable material varies by record. HCDDF 1.1 provides PDF and HTML; FIRC currently provides a PDF. The four ZModel, qSR and HCDDF 2.0 records also provide a ZIP archive. The early UG record provides a PDF. The HE preprint provides PDF, LaTeX source archive and HTML; the HE software record provides a source archive, a wheel, a reproducibility companion and verification logs.

qSR main paper version 1.4 and supplement version 1.0 are identified separately. Use the version DOI for the exact cited work; the concept DOI in catalog.json identifies the version family. HCDDF 1.1 and 2.0 are retained as separate historical publications.
